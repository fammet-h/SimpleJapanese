# 言い換え例

次の例は候補です。文脈や対象読者に合う表現を選んでください。意味が変わる場合は置き換えないでください。

| 冗長または曖昧な表現 | 言い換え例 |
|---|---|
| 〜することが可能です | 〜できます |
| 〜を実施する | 〜する |
| 〜を行うことが必要です | 〜してください / 〜が必要です |
| 〜という形になります | 〜になります / 〜です |
| 〜することができます | 〜できます |
| 〜に関して | 〜について |
| 〜の方 | 人を指す場合は 〜 / 比較の場合は文脈に応じて具体化 |
| 適宜 | 条件や時点を具体的に書く |
| 迅速に | 時間や期限を示す |
| さまざまな | 対象を具体的に示す |
| 効率化する | 何がどう変わるかを書く |
| 最適化する | 対象、基準、変更内容を書く |

置き換えによって義務、可能性、確実さの度合いを変えないでください。「場合があります」を「します」に変えると、確実さが変わります。
